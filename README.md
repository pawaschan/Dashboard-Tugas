# Dashboard Tugas Kuliah (React + Vite)

    npm install
    npm run dev       # jalankan lokal
    npm run build     # hasil di folder dist/

Upload isi `dist/` ke website pribadi, atau deploy ke Vercel/Netlify/GitHub Pages.
Ganti nama & NIM di `src/App.jsx` (konstanta MAHASISWA). Data tugas disimpan di localStorage.
